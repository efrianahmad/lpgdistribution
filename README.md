# LPG 3KG Distribution & Supply Chain Analytics Dashboard

An enterprise-grade Business Intelligence web application built with **Python**, **Streamlit**, and **Plotly** to monitor commercial run-rates, manage retail credit/receivables, and optimize warehouse safety-stock thresholds.

## 🚀 Live Interactive Demo
Test the live application here: [PASTING_LINK_STREAMLIT_GAS_KAMU_DI_SINI]

## 🧠 Features & Analytics Capabilities
* **Commercial Trends & Revenue:** High-accuracy single-axis grouped bar charts comparing Gross Omzet vs Net Profit side-by-side to track true margin density.
* **Client Distribution Analytics:** Automatic identity anonymization (`Client ID-XX`) for secure portfolio display, mapped across horizontal volume bars and funnel charts.
* **Inventory Control & Receivables:** Integrated ledger auditing for outstanding accounts receivable (unpaid invoices) and immediate critical stock warning alerts.
* **Predictive Logistics (Tab 4):** Native **Simple Linear Regression models via NumPy** calculating a 7-day future volume demand forecast, paired with interactive **What-If Simulation Sliders** for Safety Stock and Re-Order Point (ROP) optimization.

## 🛠️ Technology Stack
* **Core Language:** Python
* **Web Framework:** Streamlit
* **Data Pipelines:** Pandas & NumPy (Matrix computation for regression analytics)
* **Visualization:** Plotly Express & Plotly Graph Objects
* **Database Source:** Microsoft Excel (Sheet processing)
